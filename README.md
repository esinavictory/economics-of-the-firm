# economics-of-the-firm
# Financial Statement Analysis of Norilsk Nickel (2020–2024)

## Overview

This project presents a comprehensive financial analysis of **Norilsk Nickel (Nornickel)** based on the company's financial statements for the period **2020–2024**. The analysis was completed as a university group project for the **Firm Economics** course at the Higher School of Economics (HSE), Saint Petersburg.

The repository contains:
- A detailed analytical report (PDF)
- An Excel workbook with financial statements, calculations, and charts

## Project Objectives

The purpose of this project is to evaluate the company's financial performance, operational efficiency, and financial stability using classical financial analysis methods.

The analysis includes:

- Fixed assets analysis
- Current assets analysis
- Cost analysis
- Profitability analysis
- Horizontal financial statement analysis
- Vertical financial statement analysis
- Liquidity analysis
- Overall assessment of the company's financial position

## Financial Indicators

The project calculates and interprets numerous financial ratios, including:

### Fixed Assets
- Fixed Asset Turnover
- Fixed Asset Intensity
- Share of Non-current Assets
- Equity to Non-current Assets Ratio

### Current Assets
- Current Asset Turnover
- Inventory Turnover
- Accounts Receivable Turnover
- Working Capital
- Operating Cycle Duration

### Profitability
- Return on Assets (ROA)
- Return on Equity (ROE)
- Return on Sales (ROS)

### Financial Structure
- Asset Turnover
- Debt-to-Equity Ratio
- Operating Leverage

### Liquidity
- Current Ratio
- Quick Ratio
- Cash Ratio

## Key Findings

- Revenue and net profit declined after 2021.
- Production costs increased steadily throughout the analyzed period.
- Profitability ratios (ROA, ROE, ROS) showed a downward trend after reaching their peak in 2021.
- Asset turnover and operating efficiency decreased over time.
- Despite weaker profitability, the company maintained strong liquidity and financial stability.
- Growth in equity and investments in non-current assets indicate a long-term development strategy despite challenging market conditions.

This project was prepared for educational purposes only. The conclusions are based on publicly available financial statements and are intended solely for academic analysis.
